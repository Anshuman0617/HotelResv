# Hotel Reservation System

A database management system for managing hotel room reservations across multiple hotels in different cities.

## Project Overview

The Hotel Reservation System allows customers to search for hotels, view available rooms and room types, and make room reservations.

The system is designed to handle multiple hotels, different room types, customers, rooms, and reservations.

## Main Features

- Search for hotels by city
- View available rooms
- View different room types and prices
- Make room reservations
- View reservation details
- Cancel reservations
- Manage hotel and room information
- Manage customer information

## Database Entities

The system will contain the following main entities:

- **Hotel**
- **Room**
- **Room Type**
- **Customer**
- **Reservation**
- **Reservation Room**
